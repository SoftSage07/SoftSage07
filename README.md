### Featured Projects

#### 🔬 [Agentic Prompting Research – Financial Sentiment Analysis]([https://github.com/](https://github.com/SoftSage07/does-reasoning-help)) 
An agentic evaluation framework benchmarking LLM prompting strategies on financial text.
- Benchmarked **5 prompting strategies** (Zero-shot, Few-shot, CoT, Anchor, Agentic) on **300 labeled financial sentences**
- Improved sentiment classification accuracy from **62% → 89.67%** using Chain-of-Thought prompting (**+27% gain**)
- Identified neutral sentiment bias; refined approach with anchor prompting; automated a fully reproducible pipeline

#### 🔹 [EquiSense – AI Financial Intelligence System]([https://github.com/](https://github.com/SoftSage07/EquiSense))
An end-to-end NLP pipeline for financial news sentiment classification using **FinBERT**, deployed on Streamlit.
- Designed a **Sentiment Reliability Index (SRI)** combining source credibility, recency, and model confidence (score: 67.9)
- Engineered a feature pipeline integrating news sentiment, **VIX volatility data**, and price trends
- Automated real-time data ingestion via REST APIs; preprocessing with Pandas & NumPy; inference in PyTorch

#### 🔹 [IncluiSphere – Community Learning Platform]([https://github.com/](https://github.com/SoftSage07/Inclusiphere))
